# E-commerce Sales Dashboard (Power BI)

## Project Overview
This project analyzes e-commerce sales data using Microsoft Power BI and SQL to identify sales trends, product performance, and regional distribution. The interactive dashboard helps visualize key business metrics and supports data-driven decision-making.

## Objectives
- Analyze overall sales and profit performance
- Identify top-selling products and categories
- Track monthly sales trends
- Understand regional sales distribution
- Generate business insights from sales data

## Tools & Technologies
- Microsoft Power BI
- SQL
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## Dataset
The dataset contains information about:
- Order details
- Sales amount and profit
- Product categories
- Quantity sold
- Regional sales performance

Data was processed using SQL queries and cleaned using Power Query before building the dashboard.

## Dashboard Features
- KPI Cards: Total Sales, Profit, Quantity Sold
- Sales by Category visualization
- Monthly Sales Trend analysis
- Regional Sales Distribution
- Top Products analysis
- Interactive filters for deeper insights

## Key Insights
- Certain categories generate the majority of sales revenue
- Sales trends vary across months and regions
- Some products contribute significantly to total profit
- Data visualization helps identify opportunities for business growth
